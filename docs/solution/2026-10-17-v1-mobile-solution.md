# 2026-10-17 V1 移动端设计方案

## 信息架构

- **登录**：填写工作台账号与密码，确认隐私协议后进入移动工作区
- **值守（默认）**：会话筛选 + 会话列表 → 聊天页
- **状态**：值守概况（待人工 / 处理中 / AI 已处理）+ 渠道状态
- **我的**：账号个人信息 + 基础设置（外观 / 消息提醒 / 语言 / 隐私 / 存储空间 / 版本）
- **底部导航**：值守 / 状态 / 我的；独立悬浮毛玻璃胶囊，覆盖在页面内容之上，不单独占用底部布局高度；标签显式使用 Inter + Noto Sans SC、12px / w500

## 页面

### 值守

- 顶部：租户名（橙子科技）、移动值守、搜索入口
- Mock 会话池：30 条，覆盖 12 个平台渠道，待人工 / 人工 / AI 各 10 条；
- 筛选：全部 / 待人工 / AI / 人工
- 会话行：头像（右下角平台来源 logo）、姓名、最近消息、时间、未回复标签、未读数；未回复标签固定 20px 高，水平与垂直居中
- 平台 logo：系统内置 Telegram / WhatsApp / Instagram / X / Facebook / Meta / Messenger / TikTok / Discord / LINE / Teams / Zalo；后续业务方可在后台/后端上传自定义 logo（Conversation.channelLogoUrl 优先）
- 顶部不再展示 V1 徽标

### 聊天

- 顶部：返回、会话对象（头像 / 姓名 / 渠道 · 状态）
- 消息：客户（左，白底描边）、AI（左，白底 + AI 标签）、客服（右，深墨）、系统（居中）
- 媒体消息：图片（点击全屏预览）、视频（封面 + 播放按钮 + 时长，点击打开预览占位）、语音（播放/暂停 + 波形 + 时长，V1 为模拟播放）
- 媒体资源：V1 使用本地 asset（assets/media/），后续替换为后端媒体 URL；演示素材：订单截图、视频封面
- 输入区：无底部背景，输入框 + 发送按钮以悬浮毛玻璃胶囊覆盖在消息列表上；
- 附件按钮：输入框左侧「+」，可选择图片 / 视频 / 文件（V1 添加示例媒体消息，真实选择与上传待接入）
- 输入：文本输入 + 发送按钮；V1 仅本地 Mock 发送
- 点击头像或姓名打开客户信息抽屉：头像/客户名称、业务渠道、当前状态、负责人、转发去向
- 聊天页头部：扁平浅灰背景栏；左侧白色圆形返回按钮、44px 头像与 18px 姓名；右侧白色胶囊操作组，包含翻译与「…」客户信息按钮；不再展示渠道状态副标题与目标语言胶囊；
- 翻译入口：位于头部右侧白色胶囊操作组内的「文A」图标；点击打开翻译设置抽屉；右侧「…」和头像/姓名均可打开客户信息；
- 翻译设置抽屉：翻译开关 + 三个内联展开选择（点击后在抽屉内展开选项，不弹独立菜单）；字段标签、字段值和展开选项统一使用全局字体、14px 与 w500，选中态通过浅色背景和勾选图标表示，不使用不同字重区分——翻译源（自动（推荐）/ Google 翻译 / 腾讯翻译君 / 百度翻译 / 有道翻译 / DeepL / 火山翻译 / 彩云小译 / 腾讯交互翻译 / Papago / CNKI 学术翻译 / MyMemory / LibreTranslate / ChatGPT 免费）、源语言（自动检测 + 21 种语言）、目标语言（自动 + 21 种语言）；选中「自动」翻译源时按 Google → MyMemory → LibreTranslate → 腾讯翻译君 → 有道 → 腾讯交互 → DeepL → 火山 → 彩云 → Papago → 百度 → CNKI → ChatGPT 免费 依次尝试；
- 译文展示：气泡内原文下方用虚线分隔、灰色小字展示译文（无「译」标签）；开启翻译后，对当前会话所有文本消息调用机器翻译，即使 Mock 数据没有预置译文也会实时请求；忽略 Mock 字段中的静态译文；翻译中显示「翻译中…」，失败显示「翻译失败」，切换翻译源 / 源语言 / 目标语言后自动重新翻译
- 气泡样式：来消息白底 + 浅色描边 + 轻阴影（AI 消息带 AI 标签）；我方消息深墨底白字；浅色主题消息区背景 `#EDEDED`，深色主题继续使用 `#020617`
- 边写边译：输入框监听 + 300ms 防抖；翻译结果以「草稿译文」卡片展示，可点上下箭头图标替换输入；使用译文、发送消息或点「收起译文」后卡片收起，再次输入时自动展开；默认使用 MyMemory 机器翻译，界面提示第三方处理与敏感信息风险；翻译结果统一做 UTF-8、HTML 实体和常见 Latin-1/CP1252 乱码修复，含 U+FFFD 的结果会回退到下一个翻译源

### 状态

- 标题：状态 + 副标题「值守概况和渠道可用性。」
- 统计卡：待人工 / 处理中 / AI 已处理（数量由会话状态派生）
- 业务渠道：平台 logo + 渠道名称 + 渠道账号 + 在线状态；点击进入该渠道下的会话列表；
- 转发渠道：平台 logo + 转发目标显示名 + 渠道/目标账号 + 连接状态（已连接 / 未连接 / 未配置）；
- 两个列表独立展示，分别对应文档中的业务渠道与转发渠道；

### 我的

- 标题：我的 + 副标题「账号信息与基础设置。」
- 账号卡片：深色渐变英雄卡，头像、姓名、角色 · 租户、在线状态，底部以两个等宽信息块展示账号 ID 与租户；使用低透明度装饰圆提升层次
- 基础设置：外观（浅色 / 深色 / 系统）、消息提醒（开关）、语言（简体中文）；
- 隐私与数据：隐私（隐私协议）、存储空间（缓存统计 / 存储协议 / 清理缓存）、版本（0.1.0）；
- 设置行统一使用 34px 圆角图标底座、14px/w500 标题、13px/w500 右侧值；分组标题 12px/w600；
- 退出登录：红色实心按钮（`#EF4444`）+ 白色图标/文字，V1 点击仅展示占位提示


### 隐私与本地存储

- 隐私协议：顶部「隐私速览」用四项口径直接说明「收集什么 / 存储什么 / 如何加密 / 不会用于第三方」，正文再展开收集范围、服务端与本机存储、传输与静态加密、使用目的、第三方共享边界、保留期限与用户权利；
- 收集范围：账号与租户、客户/渠道标识、会话消息与附件、翻译文本、AI 决策上下文、运行与投递日志；
- 服务端存储：账号与租户、会话消息、客户身份、AI 决策记录、转发投递/重试日志、渠道配置；本机存储：图片/视频/语音缓存、翻译临时缓存、AI 临时结果、日志与临时文件；
- 加密：HTTPS/WSS 传输加密；数据库与对象存储使用 AES-256 或云透明加密；渠道 Token/Secret 使用 AES-GCM 独立加密，主密钥由 KMS/环境变量管理；本机缓存位于应用沙箱，敏感凭据使用系统安全存储；
- 第三方边界：不出售、不出租，不用于广告营销或用户画像；仅在翻译、AI、转发功能中向用户选择的必要服务商发送所需数据，相关功能可切换或关闭；
- 存储空间：展示本地缓存总量、分类占用与 512 MB 上限，可查看《存储协议》并清理本地缓存；清理不影响服务端消息与客户资料；
- V1 的缓存统计与清理为 Mock 状态，真实文件统计、自动清理和本地删除待接入 `path_provider` / 缓存目录后实现；
- 隐私协议与存储协议均为原型草案，正式上线前需经法务审核。

### 主题

- `AppColors` 改为语义色板，按当前亮度返回浅色/深色值；
- `MaterialApp` 同时提供 light / dark theme，默认 `ThemeMode.system`；
- 我的 → 基础设置 → 外观可切换 浅色 / 深色 / 系统；
- 毛玻璃 header、悬浮输入区、气泡、卡片、状态色（待人工/处理中/AI/在线）均适配深色。
### 设置持久化

- 使用 `shared_preferences` 保存用户设置，App 重启后自动恢复；
- 持久化范围：主题模式、消息提醒开关、翻译开关、翻译源、源语言、目标语言；
- 设置变更后立即更新界面并异步写入本地存储；
- 翻译设置在所有会话间共享；重新进入聊天页时，若翻译已开启会自动重新调用机器翻译。

## 数据与状态

- `AppStore`（ChangeNotifier）持有会话、消息、筛选、在线状态与本地缓存 Mock 统计；
- `ChatRepository` 抽象数据访问：

| 方法 | 用途 |
|---|---|
| fetchConversations | 会话列表 |
| fetchMessages(conversationId) | 会话消息 |
| fetchChannels() | 渠道在线状态 |
| fetchProfile() | 当前客服账号信息 |
| sendMessage(...) | 发送消息 |
| markRead(conversationId) | 已读 |

- `MockChatRepository`：V1 默认实现，使用 `lib/data/mock_data.dart`；
- `RemoteChatRepository`：后端占位，接入时实现；
- 登录页当前使用 Mock 登录回调；接入后端时在登录回调中完成账号密码校验并注入鉴权请求头；
- 切换方式：

```sh
flutter run --dart-define=CS_IM_USE_MOCK=false --dart-define=CS_IM_API_BASE=https://api.example.com
```

## V1 验收

- 筛选切换正确；未读 / 未回复标识正确；
- 聊天可本地发送并即时显示，返回列表后最近消息 / 时间更新；
- 状态页展示三项值守统计与渠道在线状态；
- 我的页展示账号信息与基础设置，隐私协议可见四项速览，存储空间可查看协议并清理 Mock 缓存；
- `flutter analyze` 无问题、`flutter test` 全绿。
