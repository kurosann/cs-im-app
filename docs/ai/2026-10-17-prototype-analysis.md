## 翻译（参考 V2 聊天室原型）

- V2 原型：消息区双语对照（原文 + 译文），目标语言支持「自动 / 中文 / 英语」，可切换显示/隐藏译文；
- V1 实现：聊天页头部为扁平浅灰栏，左侧白色圆形返回、44px 头像与姓名，右侧白色胶囊内为翻译与「…」客户信息；点击头像、姓名或「…」打开客户信息，翻译图标打开翻译设置抽屉；
- 抽屉内包含：翻译开关、翻译源 / 源语言 / 目标语言三个内联展开选择（点击在抽屉内展开选项，不弹独立菜单）；全局字体为 Inter + Noto Sans SC，字段标签、字段值和展开选项统一使用 14px、w500，选中项不加粗，仅用背景与勾选区分；翻译源与 vane-im-server `/im/translate/config` 对齐（13 个）：Google / 腾讯翻译君 / 百度翻译 / 有道翻译 / DeepL / 火山翻译 / 彩云小译 / 腾讯交互翻译 / Papago / CNKI 学术翻译 / MyMemory / LibreTranslate / ChatGPT 免费；语言为自动检测 + 21 种；
- 气泡样式对齐 V2 原型：来消息白底描边，我方深墨底；译文以虚线分隔、灰字展示在气泡内；
- 译文来源：V1 为 Mock 数据字段（translatedText / translatedLanguage），后续替换为后端翻译接口。

## 边写边译（参考 vane-im-flutter）

- vane-im-flutter 实现：输入监听 + 300ms 防抖；翻译服务优先走 `/im/translate`，不可用时回落公共机器翻译源；
- 草稿译文卡片：翻译中显示 loading，完成后展示译文与上下箭头图标（可替换输入框内容）；使用译文、发送或点收起图标后卡片收起，再次输入自动展开，并提供折叠；
- cs-im-app V1：同样 300ms 防抖 + 草稿译文卡片 + 上下箭头按钮；机器翻译源与 vane-im-flutter / vane-im-server 对齐：13 个翻译源，自动时按可用性顺序回落；语言列表与 vane-im-flutter 完全一致；界面提示「译文由第三方机器翻译服务生成，请勿输入敏感信息」。

## 媒体消息（产品新增）

- 气泡支持图片 / 视频 / 语音三类媒体消息；
- 图片：圆角封面，点击全屏预览（支持缩放）；
- 视频：封面 + 播放按钮 + 时长角标，点击打开预览占位（真实播放待接入媒体服务）；
- 语音：播放/暂停按钮 + 波形 + 时长，V1 为模拟播放进度；
- V1 媒体资源使用 `assets/media/` 本地素材，模型字段预留 `mediaAsset` / `durationSeconds`，后续替换为媒体 URL。

## 隐私与存储（产品新增）

- 隐私协议页首屏提供「隐私速览」，直接回答四个高频问题：
  - 收集什么：账号信息、会话消息与附件、客户/渠道标识、翻译文本、AI 决策上下文、运行日志；
  - 存储什么：服务端保存会话、客户、AI 记录与投递日志；本机保存媒体缓存、翻译/AI 临时结果和临时文件；
  - 怎么加密：HTTPS/WSS、数据库/对象存储加密、渠道凭据 AES-GCM、本机应用沙箱与系统安全存储；
  - 不会用于第三方：不出售/出租，不用于广告或画像；仅在翻译、AI、转发时向所选服务商发送必要数据。
- 「我的 → 存储空间」展示 128 MB Mock 缓存、512 MB 上限和分类占用，可查看《存储协议》并清理缓存；
- V1 的缓存数字与清理目前为演示状态，不实际删除本地文件；接入媒体服务后再替换为真实目录统计和清理。
