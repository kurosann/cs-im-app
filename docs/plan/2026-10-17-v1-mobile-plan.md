# 2026-10-17 V1 移动端实施计划

## 目标

交付纯前端 V1 移动端：值守 / 聊天 / 状态 / 我的四块，数据全部来自 Mock，预留后端接入边界。

## 假设

- 视觉以原型 `/mobile`（V1）为准；
- 本阶段不接后端 API、不做登录/推送/多语言/V2 能力；
- Android / iOS 为主，Web 仅用于预览与构建验证。

## 风险

- 原型为静态演示稿，聊天页 / 状态页缺少细节，按同一视觉语言扩展；
- 原型数据为演示数据，不可用于真实业务校验；
- 后端接口以《cs-im-route 需求方案》接口章节为准，接入前需完成接口评审。
