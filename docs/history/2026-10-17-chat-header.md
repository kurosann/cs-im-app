# 2026-10-17 聊天头部布局改版

## 变更内容

- 聊天页头部由悬浮圆角毛玻璃条改为扁平浅灰栏，与 `#EDEDED` 消息区背景衔接；
- 左侧改为白色圆形返回按钮，44px 会话头像与 18px 姓名，移除渠道/状态副标题；
- 右侧改为白色胶囊操作组，放置翻译与三点客户信息按钮；
- 翻译开启时「文A」图标使用深色圆形激活态；
- 客户信息可通过头像、姓名或右侧「…」按钮打开；
- 聊天消息列表顶部留白同步缩小，适配新头部高度。

## 原因

按产品提供的新聊天头部参考图调整布局和视觉层级。

- 聊天头部、客户信息抽屉与翻译设置测试通过；
- `flutter build web --release --no-web-resources-cdn` 通过；
