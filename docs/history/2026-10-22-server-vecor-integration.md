# 对接 cs-im-server vecor：移动值守与翻译

- App 新建个人分支 `vecor`，包含此前翻译延迟与后端回退改动。
- 登录页使用真实账号/邮箱和密码，调用 `/api/v1/auth/login`，验证客服权限并使用服务端 `userKey` 作为发信身份。
- 个人信息采用登录结果与会话接口；退出时撤销会话并清空内存缓存，旧会话尚未完成的请求不能重新写入工作区。
- 会话列表兼容 `{items, total}` 分页与旧数组响应，展示服务端未读数和回复状态；无人工负责人且最后一条为 AI 消息时显示「AI 已处理」。
- 已读调用会话级接口；现有 8 秒轮询继续拉取客户、AI 和客服消息。
- 自动翻译优先请求新翻译模块；异常或超时后使用 vecor 的 LLM/Google 翻译接口，再保留客户端回退；手动翻译源保持原流程。
- 当前范围为移动值守与翻译。AI 员工、知识库和服务商管理继续使用工作台。
- 接口契约依据同一工作区 cs-im-server vecor 源码，运行方式见仓库 README。

## 已接入的值守动作

- 会话搜索使用 `GET /admin/v1/conversations?keyword=`。
- 客户信息可以认领、结束和转发，并查看投递记录。
- 状态页优先使用 `GET /admin/v1/channel-monitor`，旧服务端回退到应用列表。
- 登录后订阅 `GET /admin/v1/realtime`，事件到达后刷新工作区；8 秒轮询仍作为兜底。
- 我的页可以修改密码，调用 `POST /api/v1/auth/password`。
