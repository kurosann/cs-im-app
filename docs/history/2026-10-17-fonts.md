# 2026-10-17 全局字体与翻译设置统一

## 变更内容

- 新增 `assets/fonts/` 字体资源：Inter Regular / Medium / SemiBold / Bold，以及 Noto Sans SC Regular / Medium / Bold；
- `ThemeData` 全局使用 `Inter`，中文以 `NotoSansSC` 作为 fallback；
- 翻译设置中的字段标签和下拉选项统一使用全局字体；字段标签由 13px / w600 调整为 14px / w500，与字段值保持一致；
- 翻译源 / 源语言 / 目标语言的展开选项中，选中项不再使用 w600 加粗，统一为 w500，选中状态继续通过浅色背景和勾选图标表示；
- 字体授权文件归档在 `assets/fonts/licenses/`，并作为 asset 打包。

## 原因

解决全局字体不一致，以及翻译设置里标题、字段值和下拉选项看起来使用不同字体/字重的问题。

## 说明

- Inter 负责英文、数字与拉丁字符；
- Noto Sans SC 负责中文字符回退，因此混合文本中会按字符脚本自动切换，这是预期行为；
- 如需所有字符完全同一套字形，可改为仅使用 Noto Sans SC。
