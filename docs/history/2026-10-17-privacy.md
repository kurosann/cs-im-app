# 2026-10-17 隐私协议页

## 变更内容

- 「我的 → 基础设置」新增「隐私」入口；
- 新增隐私协议页（草案）：引言、信息收集、信息存储、传输与静态加密、信息使用、第三方服务、存储保留、安全、用户权利、未成年人、协议更新、联系方式；
- 首屏新增「隐私速览」，直接说明收集什么、存储什么、如何加密、不会用于第三方；
- 协议中明确说明机器翻译、AI 与转发功能会按需向所选服务商发送必要数据，并提示第三方处理与敏感信息风险；
- 支持浅色/深色主题阅读。

## 原因

产品要求基础设置可查看隐私协议。

## 验证

- `flutter analyze` / `flutter test` / `flutter build web` 通过；
