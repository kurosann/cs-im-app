# 2026-10-18 底部导航字体统一

## 变更内容

- 底部导航「值守 / 状态 / 我的」标签显式指定 `appFontFamily = Inter`；
- 中文回退显式指定 `NotoSansSC`；
- 标签字重由 `w400` 调整为 `w500`，行高设为 `1.2`；
- 新增测试断言导航标签字体、回退字体和字重。

## 原因

导航位于页面内容外的悬浮层，之前依赖全局默认字体继承，和系统设置项文字视觉不一致。

## 验证

- `flutter analyze` 通过；
- 底部导航毛玻璃与字体测试通过；
- `flutter build web --release --no-web-resources-cdn` 通过；
- 截图见 `docs/assets/app-v1-duty-dark.png`。
