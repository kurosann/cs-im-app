# CS-IM App 文档中心

本目录用于分类管理 CS-IM V1 移动端的计划、方案、规则、AI 产物、历史与素材。

| 目录 | 用途 | 主要产物 |
|---|---|---|
| plan/ | 实施计划与里程碑 | V1 计划、迭代待办 |
| solution/ | 设计方案 | 信息架构、视觉规范、数据与接口边界 |
| rules/ | 项目规则 | 视觉优先原型、Mock-first、质量门禁 |
| ai/ | AI 产物 | 原型分析、生成记录、走查结论 |
| history/ | 变更记录 | 每次有意义的改动 |
| assets/ | 静态素材 | 原型截图等 |

## 约定

- 文件名 `YYYY-MM-DD-short-name.md`，内容使用中文；
- 文档内链接使用仓库相对路径，不写本机绝对路径；
- 事实冲突时，以「原型实测样式 + 当前代码」为准；`ai/` 下的内容仅作参考；
- 重大变更同步更新 `history/`。
